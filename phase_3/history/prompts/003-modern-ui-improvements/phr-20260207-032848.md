Task: Implement the Update/Edit functionality for tasks in the dashboard, allowing users to modify task title and description.

## Response snapshot

Successfully implemented task update feature with:

1. **State Management**: Added edit state tracking (editingTaskId, editTitle, editDescription, isUpdating)

2. **Handler Functions**:
   - `handleStartEdit(task)`: Initiates edit mode with pre-populated fields
   - `handleCancelEdit()`: Cancels edit without saving
   - `handleUpdateTask(taskId)`: Submits PATCH request to backend

3. **UI Components**:
   - Edit form with title and description fields
   - Save and Cancel buttons
   - Edit button visible on task hover
   - Smooth transitions between view and edit modes

4. **Backend Integration**:
   - Uses existing PATCH /api/v1/tasks/{id} endpoint (T049)
   - Sends title and description in request body
   - Handles errors with user-friendly messages
   - Updates local state immediately on success

5. **Features**:
   - Form validation (title required)
   - Loading states during API request
   - Error handling and display
   - Responsive design (mobile and desktop)
   - Accessibility (unique form IDs, labels)
